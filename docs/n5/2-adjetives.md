Each adjective is shown in four forms:

* **Affirmative**
* **Negative**
* **Past**
* **Past Negative**

# Notes

## い-Adjectives

The adjective itself changes:

```text
Affirmative:
大きい

Negative:
大きくない

Past:
大きかった

Past Negative:
大きくなかった
```

## な-Adjectives

The adjective itself generally does not change. The copula changes instead:

```text
Affirmative:
元気だ

Negative:
元気ではない

Past:
元気だった

Past Negative:
元気ではなかった
```

When an adjective directly modifies a noun:

```text
大きい犬
元気な人
```

The `な` is used before a noun with な-adjectives.
