# Japanese Verbs — Verb Groups and Present Tense Forms

This document contains the verbs from my vocabulary list, organized by Japanese verb group and original vocabulary level.

## Verb Groups

* **Group 1:** Godan verbs
* **Group 2:** Ichidan verbs
* **Group 3:** Irregular verbs

## Form Order

| Form                       | Meaning                             |
| -------------------------- | ----------------------------------- |
| Dictionary Form            | Basic verb form                     |
| Present Affirmative Formal | `ます` form                           |
| Present Negative Formal    | `ません` form                          |
| Present Affirmative        | Plain form; same as dictionary form |
| Present Negative           | `ない` form                           |

## Notes

* The **Dictionary Form** is also the **Present Affirmative Plain Form**.
* The **Present Affirmative Formal** form uses `ます`.
* The **Present Negative Formal** form uses `ません`.
* The **Present Negative Plain** form uses the appropriate `ない` conjugation.
* `有る` is the verb `ある`. Its negative is conventionally `無い` rather than `有らない`.
